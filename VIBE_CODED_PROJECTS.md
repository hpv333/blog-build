## 3. AI Security Auditor

**Status:** Built, Deployed
**Stack:** React.js, Google Gemini API, Supabase, Vercel

### What It Is
A web application that leverages Google Gemini's AI capabilities to perform intelligent security audits and vulnerability assessments. Users can input code, configurations, or system descriptions and receive AI-powered security analysis.

### Key Features
- **AI-Powered Analysis:** Uses Google Gemini API to analyze code and configurations for security vulnerabilities
- **Vulnerability Assessment:** Identifies common security issues (XSS, SQL injection, auth flaws, etc.)
- **Report Generation:** Produces structured security audit reports with severity ratings
- **Quota Management:** Built-in guardrails for API usage with UI warnings when approaching limits

### Technical Highlights
- **Zero-Cost Architecture:** Entire stack runs on free tiers:
  - Google Gemini API (free tier)
  - Supabase (free tier for auth and data storage)
  - GitHub (source control)
  - Vercel (hosting and deployment)
- Quota guardrails prevent unexpected API costs
- UI warnings built in to alert users when approaching usage limits
- Scaffolded in Lovable, refined with Cursor

### Why It Matters
Demonstrates the ability to integrate AI APIs into practical security tooling — combining frontend development skills with AI/ML API integration and responsible usage patterns (quota management, cost awareness).

## 2. AquaRemind

**Live:** [https://aqua-hydrate.vercel.app/](https://aqua-hydrate.vercel.app/)
**Status:** Live, Deployed, Maintained
**Stack:** React.js, PWA, Vercel

### What It Is
A wellness app focused on hydration and supplement schedule management. Sends smart reminders to help users maintain consistent hydration habits and never miss supplement doses.

### Key Features
- **Hydration Reminders:** Configurable intervals for water intake reminders
- **Supplement Scheduling:** Track and manage supplement/vitamin schedules with timing
- **Smart Notifications:** Browser-based push notifications for timely reminders
- **Progress Dashboard:** Visual tracking of daily hydration goals
- **PWA Installable:** Works as a standalone app on mobile devices

### Technical Highlights
- Scaffolded in Lovable, refined with Cursor and Claude
- Notification API integration for browser-based reminders
- Clean, minimal UI focused on quick daily interactions
- Deployed on Vercel with continuous deployment from GitHub

### Why It Exists
Born from a personal need — Hari Priya uses multiple supplements alongside a Diet system and needed a simple, no-friction way to stay on schedule. Built it, shipped it, uses it daily.
